# Demo Flow

## Suggested demo order

1. Login with `admin@minijira.com` and get JWT.
2. Create a new project.
3. Add a developer to the project.
4. Create a task inside that project.
5. Assign the task to the developer.
6. Move task from `TODO` to `IN_PROGRESS`.
7. Add a comment to the task.
8. Show filtered tasks.
9. Show dashboard counts.
10. Explain activity log entries returned in task details.

## What to emphasize while presenting

- Clean architecture
- JWT security
- role-based access
- workflow validation
- MySQL relational design
- activity tracking
- pagination and dashboard support
